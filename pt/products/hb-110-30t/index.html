Introdução
#

A Máquina CNC de Furação Horizontal e Fresagem HB-110-30T foi projetada para oferecer precisão, confiabilidade e versatilidade para uma ampla gama de aplicações industriais de usinagem. Este artigo apresenta uma análise detalhada de suas características, especificações técnicas e opções disponíveis.

Equipamento Padrão
#

  • Escalas lineares absolutas Heidenhain nos eixos X, Y, Z e W
  • Encoder absoluto angular Heidenhain no eixo B
  • Resfriador de óleo do spindle
  • Sistema centralizado de lubrificação automática
  • Sistema de refrigeração
  • Sistema de sopro de ar
  • Ar-condicionado para o gabinete elétrico
  • Lâmpada de trabalho
  • Transportador de cavacos para a mesa
  • Função automática de desligamento M30
  • Volante portátil MPG
  • Lâmpada de alarme
  • Caixa de ferramentas com ferramentas de ajuste
  • Blocos e parafusos de nivelamento

Equipamento Opcional
#

  • Refrigeração através do spindle (pressão de 20 bar)
  • Transportador de cavacos com balde
  • Suporte para spindle
  • Protetor de respingos para mesa
  • Transformador para tensões diferentes de 220V
  • Cabeçote de fresagem em ângulo reto
  • Placa angular
  • Removedor de óleo
